# 实验选修客户端

这是一个本地 Tkinter 客户端，用于读取教学选排课系统中的实验列表，并在确认后提交单个实验的选修请求。

## 使用

1. 安装 Python 3.9 或更高版本。
2. 在本目录运行：

   ```powershell
   python .\experiment_client.py
   ```

3. 按名称分别填写 `ASP.NET_SessionId`、`COOKIES_KEY_USERNAME`、`CurrentCourseMenu` 和 `fzsy` 的值；空的 `CurrentCourseMenu` 可以留空。敏感值默认隐藏，可用“显示 Cookie”开关查看。
4. 点击“登录并抓取课程”，选择课程后刷新实验列表；界面会同时显示“可选实验”和“已选实验”两个标签页。
5. 双击实验或选中后点击“选择当前实验”。提交前会弹出包含课程、时间、教师、教室和人数的二次确认框。
6. 需要等待名额时，选中目标实验后点击“自动重试选修”，设置请求间隔（默认 3 秒，最低 2 秒）。服务器确认成功、检测到已选、课堂已满、Cookie 失效或发生网络错误时会自动停止，也可以随时点击“停止重试”。
7. “显示虚拟仿真”默认关闭；打开后客户端会额外请求虚拟仿真分类，并在可选列表中展示教室、名称或类别标注为虚拟、仿真的实验。虚拟实验会以 `[虚拟]` 标记显示，选课与自动重试流程和常规实验一致。已选实验始终完整显示。

Cookie 只在当前进程内存中使用，不写入文件。如果学校更换地址，需要修改 `experiment_client.py` 顶部的 `BASE_URL`。
